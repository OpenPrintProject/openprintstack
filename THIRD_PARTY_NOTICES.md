## The web app's build

`pnpm build` bundles npm packages into the web app's files in `apps/web/dist`, which the server sends to every browser. Vite lists the packages whose code is in those scripts, each with its licence, in `apps/web/dist/licenses.txt`, and the server serves that list at `/licenses.txt`. It includes React, Radix UI, TanStack Router, Query and Form, sonner, Lucide (ISC), class-variance-authority (Apache-2.0) and Zod, among others.

Three more arrive through the stylesheet (`apps/web/src/styles/index.css`), which Vite's list doesn't cover. Their notices follow. (The server's build, `apps/server/dist`, holds only this repository's code: it loads its npm dependencies from `node_modules`.)
